# SafeStep

SafeStep is an Android application developed as an academic project focused on child safety, location tracking, and emergency communication between parents and children.

## 📱 About the Project

The application provides separate experiences for parents and children, with the goal of giving parents better visibility into their child's location while providing children with a simple way to request help in an emergency.

## 🚀 Features

- Parent and child user roles
- User registration and login
- Child location tracking
- Parent map interface
- Emergency SOS functionality
- Location sharing during emergency situations
- Parent notifications
- Simple and intuitive mobile interface

## 🛠 Technologies

- Java
- Android Studio
- Android SDK
- Gradle
- Location Services
- Mobile Application Development

## 🎯 Project Goal

The goal of SafeStep is to explore how mobile technologies and location-based services can be used to create practical safety solutions while developing hands-on experience in Android application development.
